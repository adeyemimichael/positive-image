BEFORE PRODUCTION DEPLOYMENT
================================================================================

CRITICAL STEPS:

1. REGENERATE PAYSTACK KEYS
   → Go to: https://dashboard.paystack.com/#/settings/developers
   → Regenerate both Secret and Public keys
   → Switch to LIVE mode (not Test)

2. SET VERCEL ENVIRONMENT VARIABLES
   → PAYSTACK_SECRET_KEY = sk_live_YOUR_KEY
   → VITE_PAYSTACK_PUBLIC_KEY = pk_live_YOUR_KEY
   → VITE_APP_URL = https://positiveimgeschools.com
   → VITE_ADMIN_PASSWORD_HASH = (optional)

3. CHANGE ADMIN PASSWORD
   → Default is 'adminadmin'
   → Generate hash and set in Vercel

4. ENABLE 2FA ON PAYSTACK
   → Settings → Security → Two-Factor Authentication

5. CONFIGURE WEBHOOKS (Optional)
   → Settings → Webhooks
   → URL: https://positiveimgeschools.com/api/webhook
